# 📊 Event Resource Allocation using Greedy Algorithms

This is a mini-project for **CSE246 - Algorithm Design and Analysis**. It implements a scheduling and resource allocation system using **Merge Sort** and a **Greedy Fractional Knapsack Algorithm**.

## 💡 Project Description

The program accepts a list of events, each with:

- Start time
- End time
- Priority
- Resource requirement

It then:

1. **Sorts events by priority** using Merge Sort.
2. **Allocates resources** using a Greedy approach inspired by the Fractional Knapsack problem.
3. **Displays a resource allocation table**.

## 🧠 Algorithms Used

- **Merge Sort**: For sorting events based on priority or start time.
- **Greedy Fractional Knapsack**: For optimal allocation of limited resources.
